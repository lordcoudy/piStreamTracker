# Project orientation

Always prefix shell commands with `rtk`; use `rtk proxy <command>` when no
specialized RTK command applies.

Before exploring or changing this project, read [PROJECT_MAP.md](PROJECT_MAP.md)
for module ownership, runtime flows, operational caveats, and relevant tests.
Read the referenced source and tests for the area you are working on.

When changes alter the architecture, configuration behavior, deployment, or a
documented caveat, update the corresponding part of the map.
